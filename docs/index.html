Six puzzles for a real machine.

A robot on a grid. Sixteen registers, four flags, twenty-seven instructions, and no if statement — so you build one. Every puzzle here is solved by a Weft-8 program you write yourself, and the same machine is what runs it.

; plate 04 — feel for the wall
east:   LDI 1            ; 1 = east
        OUT MOVE
        LOAD BUMPED       ; 1 if it was blocked
        JZ  east          ; 0 = it moved, go again
        LDI 2            ; 2 = south
        OUT MOVE
        HLT
  • The checker is the machine. A puzzle counts as solved only when a program you wrote actually drove the robot onto the goal with every flag collected.
  • Every level ships a working solution and the test suite runs it, so no puzzle can be one nobody has ever solved.
  • Nothing is hidden. The world is a few hundred lines; the machine is one file.
  • Offline. No account, no server, no telemetry — it runs from a USB stick.
