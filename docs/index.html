Six puzzles for a real machine.

A robot on a grid. Sixteen registers, four flags, twenty-seven instructions — and no assembler, so you build one. Every puzzle here is solved by a Weft-8 program you write yourself, and the same machine is what runs it.

PLATE 01

First thread

Three squares, nothing in the way. The shortest program that works.

PLATE 02

PLATE 06

What a solution looks like

; plate 04 — feel for the wall
east:
  LDI 1        ; 1 = east
  OUT
  MOVE
  LOAD
  ; a bumper sets a flag; the branch reads it

No assembler ships with the machine — writing the one that turns this text into instructions is the first puzzle, and it is the same code the site itself runs.

The workshop floor

About this sheet

One 8-bit machine, six problems, and nothing hidden: the instruction set is printed in the workshop, the flags are visible while the program runs, and every puzzle is solvable with the same twenty-seven instructions. Offline, no account, no network calls.
